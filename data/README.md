# Dataset

This folder contains the original Superstore dataset used in the Customer Intelligence & Profitability Analysis project.

## File

- `_superstore.xls` — Original dataset used for the analysis.

## Purpose

The dataset supports analysis of:
- Sales and profitability
- Customer purchasing behavior
- Repeat customers
- RFM customer segmentation
- KPI validation across SQL, Python, and Tableau

## Data handling

The dataset will be inspected and cleaned before analysis. Any data-quality issues and cleaning decisions will be documented in the project.
